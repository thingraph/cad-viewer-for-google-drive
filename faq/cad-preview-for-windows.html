CAD Preview for Windows

CAD Preview for Windows is a free desktop application for viewing 2D CAD (DWG, DXF) and 3D models on Windows — including glTF, GLB, OBJ, FBX, STL, IFC, STEP, IGS, and IGES. Install once, then open files from Explorer or from inside the app.

Video demo

Download

Installers are on Windows Installers — for example CADPreview-Setup-0.1.3.exe and previous releases.

DWG Preview vs CAD Preview on Windows

  • DWG Preview — DWG and DXF only (2D CAD).
  • CAD Preview — 2D and 3D formats; choose this if you work with STEP, IFC, glTF, or other 3D files.

Browser & Google Drive alternatives

Use CAD Viewer (browser) or CAD Viewer for Google Drive™ when you do not need a desktop install.
