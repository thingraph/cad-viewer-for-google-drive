Installation · Google Drive™

How to Install CAD Viewer from Google Workspace Marketplace

To open CAD files from Google Drive™ with Open with, install one of the Thingraph apps from Google Workspace Marketplace. Installation is free and takes a few minutes. This guide covers which app to choose, the install steps, permissions, and what to do after install.

Which app should I install?

Thingraph publishes three Google Drive apps. Install the one that matches your file types:

  • DWG Viewer — DWG and DXF only (2D CAD).
  • CAD Viewer — DWG, DXF, and 3D models (glTF, GLB, OBJ, FBX, STL, IFC, STEP, IGS, IGES).
  • CAD Editor — 3D models only, with scene editing (no DWG/DXF).

Not sure? Read CAD Viewer vs DWG Viewer vs CAD Editor.

Install steps

  1. Open the Install page. Go to cad.thingraph.site/install and click Install next to the app you need. You can also open the Marketplace links above directly.
  2. Sign in with Google. Use the same Google account you use for Google Drive. Workspace admin policies may require admin approval for third-party apps in some organizations.
  3. Review and accept permissions. The app requests limited Drive access (see below). Click Allow or Install to complete setup.
  4. Verify in Google Drive. Open drive.google.com, right-click a supported file, and confirm Open with lists your new app.
  5. Open a file. Select the viewer. The file loads in a new tab at cad.thingraph.site.

What permissions does the app request?

Thingraph Google Drive apps use OAuth 2.0 with restricted scopes:

  • https://www.googleapis.com/auth/drive.file — access only to files you open with the app (or create with it). The app cannot list or read your entire Drive.
  • drive.install (where applicable) — registers the app in Open with for supported extensions.

The app has read-only access to opened files for viewing. It cannot modify or delete your Drive files. More detail: Is CAD Viewer safe?

After installation: first open

On first use you may need to:

  • Allow pop-ups for cad.thingraph.site if sign-in opens in a popup
  • Complete Google OAuth in the browser tab that opens
  • Wait for the viewer to download and parse the file (large DWG or IFC files take longer)

Troubleshooting install issues

App not in Open with menu

  • Confirm install finished in Marketplace (check Google Account permissions).
  • Refresh Google Drive (hard refresh: Ctrl+Shift+R / Cmd+Shift+R).
  • File extension must match the app — DWG Viewer only lists .dwg / .dxf.

Full guide: Open with not showing.

Admin blocked the app

Google Workspace admins can restrict Marketplace apps. Ask your IT admin to allow Thingraph CAD Viewer or DWG Viewer, or use local upload without Drive integration.

Uninstall or revoke access

Remove the app at myaccount.google.com/permissions → select the Thingraph app → Remove access. You can reinstall anytime from Install.
