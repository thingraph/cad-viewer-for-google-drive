DWG Preview for Windows

DWG Preview for Windows is a free desktop application for opening and viewing DWG and DXF drawings on Windows — without AutoCAD. Install the .exe package, then double-click CAD files or open them from the app.

Video demo

Download

Get the latest installer and older releases from Windows Installers. Current builds are listed by full file name (for example DWGPreview-Setup-0.1.3.exe).

Supported formats

DWG and DXF (2D CAD). For 3D models on Windows, use CAD Preview for Windows.

Browser alternative

Prefer no install? Use the web DWG Viewer or open DWG from Google Drive™ in the browser.
