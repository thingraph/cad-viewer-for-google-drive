Troubleshooting · Google Drive™

CAD Viewer Not Showing in Google Drive「Open with」Menu

You right-click a DWG or 3D file in Google Drive™ but DWG Viewer, CAD Viewer, or CAD Editor is missing from Open with. This guide walks through the most common causes and fixes — in order from quickest to check.

Checklist (try these first)

  1. Install the app from Install or Google Workspace Marketplace — visiting the viewer website alone does not register Open with.
  2. Complete Google authorization — click Allow/Install until Marketplace shows the app as installed.
  3. Same Google account in Drive and during install (check the profile icon in drive.google.com).
  4. Correct file extension — DWG Viewer only lists for .dwg / .dxf; 3D apps need matching 3D extensions.
  5. Hard refresh Drive — Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac).

Cause 1: App not installed from Marketplace

Open with only lists apps registered through Google Workspace Marketplace. Opening cad.thingraph.site in a tab does not add the app to Drive.

Fix:

  1. Go to Install guide or Install.
  2. Install DWG Viewer, CAD Viewer, or CAD Editor as needed.
  3. Return to Drive and right-click the file again.

Cause 2: Wrong app for file type

Each app only appears for extensions it supports:

  • DWG Viewer — .dwg, .dxf only
  • CAD Viewer — DWG, DXF, glTF, GLB, OBJ, FBX, STL, IFC, STP, STEP, IGS, IGES
  • CAD Editor — 3D formats only (no DWG/DXF)

A .pdf or .docx will never show CAD Viewer. A .dwg will not show CAD Editor. See app comparison.

Cause 3: Different Google account

You installed with one account but Drive is signed into another (common with multiple Chrome profiles or work/personal switching).

Fix:

  • Check which account is active in Drive (top-right avatar).
  • Install the app while signed into that account, or switch Drive to the account that already installed it.
  • Review installed apps at Google Account permissions.

Cause 4: Incomplete or revoked authorization

If you denied permissions or removed access, Open with may disappear.

Fix:

  1. Visit myaccount.google.com/permissions.
  2. If Thingraph app is missing, reinstall from Install.
  3. If present but broken, Remove access, then reinstall and accept permissions again.

Cause 5: Google Workspace admin restrictions

Company and school Workspace accounts may block unapproved Marketplace apps. Install may fail silently or Open with never lists third-party viewers.

Fix:

  • Ask your IT admin to allow Thingraph CAD Viewer / DWG Viewer in the Admin console.
  • Until approved, use local DWG Viewer (upload from computer, no Drive).

Cause 6: Browser or Drive UI quirks

  • Try another browser (Chrome recommended).
  • Use the ⋮ three-dot menu on the file, not only right-click.
  • Click Open with → Connect more apps and search for “CAD Viewer” or “DWG Viewer”.
  • Disable ad blockers temporarily on drive.google.com.

Cause 7: Pop-up blocked after selecting Open with

Sometimes the app is in the menu but the viewer tab does not open because the browser blocked a pop-up.

Fix: Allow pop-ups for cad.thingraph.site and accounts.google.com, then try again.

Still not working?

  • Confirm the file opens locally at DWG Viewer — rules out a corrupt file.
  • Read CAD Viewer Support or DWG Viewer Support.
  • Email thingraph@outlook.com with: Google account type (personal/Workspace), file extension, screenshot of Open with menu, and whether Marketplace shows the app as installed.
